# Symbols

<link-summary>Symbols and subscripts used throughout the formulae.</link-summary>

## General gear symbols

| Symbol | Description | Unit |
|--------|-------------|------|
| $m$, $m_n$ | Module (normal module for helical gears) | mm |
| $m_t$ | Transverse (radial) module, $m_n / \cos\beta$ | mm |
| $\alpha$, $\alpha_n$ | Pressure angle (normal pressure angle) | ° |
| $\alpha_t$ | Transverse pressure angle | ° |
| $\alpha_w$, $\alpha_{wt}$ | Working (transverse) pressure angle of a meshing pair | ° |
| $\beta$ | Helix angle at the reference cylinder | ° |
| $\gamma$ | Lead angle (worm) | ° |
| $z$ | Number of teeth, grooves, leaves or thread starts | - |
| $x$ | Profile shift coefficient | - |
| $y$ | Centre distance increment factor | - |
| $d$ | Reference (pitch) diameter | mm |
| $d_b$ | Base diameter | mm |
| $d_a$ | Tip (outside) diameter | mm |
| $d_f$ | Root diameter | mm |
| $d_w$ | Working pitch diameter | mm |
| $h_a$ | Addendum | mm |
| $h_f$ | Dedendum | mm |
| $h$ | Whole depth, $h_a + h_f$ | mm |
| $c$ | Bottom clearance | mm |
| $p$ | Circular pitch (chain and belt: pitch) | mm |
| $p_b$ | Base pitch | mm |
| $p_x$ | Axial pitch | mm |
| $p_z$ | Lead | mm |
| $s$ | Circular tooth thickness | mm |
| $j_t$ | Circular backlash | mm |
| $j_n$ | Normal backlash | mm |
| $b$ | Face width | mm |
| $a$ | Standard centre distance | mm |
| $a_w$ | Working centre distance | mm |
| $\mathrm{inv}\,\alpha$ | Involute function, $\tan\alpha - \alpha$ (α in radians) | rad |
| $\varepsilon_\alpha$ | Transverse (radial) contact ratio | - |
| $\varepsilon_\beta$ | Axial (overlap) contact ratio | - |
| $\varepsilon_\gamma$ | Total contact ratio, $\varepsilon_\alpha + \varepsilon_\beta$ | - |
| $i$ | Gear ratio | - |

## Bevel and hypoid symbols

| Symbol | Description | Unit |
|--------|-------------|------|
| $\Sigma$ | Shaft angle | ° |
| $\delta$ | Pitch cone angle | ° |
| $R_e$ | Outer cone distance | mm |
| $R_m$ | Mean cone distance | mm |
| $\theta_a$ | Addendum angle | ° |
| $\theta_f$ | Dedendum angle | ° |
| $\delta_a$ | Tip (face) cone angle, $\delta + \theta_a$ | ° |
| $\delta_f$ | Root cone angle, $\delta - \theta_f$ | ° |
| $z_v$ | Virtual (Tredgold) tooth number, $z / \cos\delta$ | - |
| $\beta_m$ | Mean spiral angle | ° |
| $r_c$ | Cutter radius | mm |
| $E$ | Hypoid offset | mm |
| $\varepsilon$ | Hypoid offset angle in the pitch plane | ° |

## Worm, cycloidal and planetary symbols

| Symbol | Description | Unit |
|--------|-------------|------|
| $q$ | Worm diameter quotient, $d_1 / m$ | - |
| $z_1$ | Worm thread starts (worm) | - |
| $L$ | Lead of the worm, $z_1 \pi m$ | mm |
| $r_a$ | Addendum arc radius (cycloidal) | mm |
| $z_s$, $z_p$, $z_r$ | Sun, planet and ring teeth | - |
| $\omega_s$, $\omega_r$, $\omega_c$ | Angular speeds of sun, ring and carrier | rpm |
| $N$ | Number of planets | - |

## Belt and chain symbols

| Symbol | Description | Unit |
|--------|-------------|------|
| $p$ | Belt or chain pitch | mm |
| $PLD$ | Pitch line differential (HTD pulley) | mm |
| $d_o$ | Pulley outside diameter | mm |
| $d_r$ | Pulley root diameter | mm |
| $h_t$ | Belt tooth height (groove depth) | mm |
| $R_1$, $R_2$ | Belt tooth head radius and foot radius | mm |
| $d_1$ | Chain roller diameter | mm |
| $b_1$ | Chain inner width | mm |
| $r_i$ | Roller seating radius | mm |
| $r_e$ | Tooth flank radius | mm |
| $C$ | Shaft centre distance of a belt or chain drive | mm |
| $L_p$ | Pitch path length | mm |
| $X$ | Number of chain links | - |
